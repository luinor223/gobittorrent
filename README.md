# gobittorrent

A BitTorrent desktop client written in Go.

> 🚧 Work in progress - not usable yet.

## Goals

- Download and seed torrents from `.torrent` files and magnet links
- Simple desktop UI
- Pure Go engine, no external torrent libraries
